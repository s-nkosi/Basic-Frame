# My First Java GUI 🖥️

This is my first Java Swing GUI project, created while learning **Java and Object-Oriented Programming**.

## 📌 About the Project

The project demonstrates how to create a basic graphical user interface using Java Swing. It includes a custom `JFrame` with basic window properties such as size, title, background, location, and closing behavior.

## 🛠️ Technologies Used

* Java ☕
* Java Swing
* NetBeans
* JFrame

## 📂 Project Structure

```text
src/
├── firstframe/
│   └── FirstFrame.java
│
└── za/ac/tut/ui/
    └── BasicFrame.java
```

## ▶️ How It Works

The `FirstFrame` class contains the `main()` method and creates an instance of `BasicFrame`.

The `BasicFrame` class extends `JFrame` and creates the GUI window.

The application displays a **500 × 500** window titled **"My first GUI"**.

## 🎯 What I Learned

* Creating a `JFrame`
* Using constructors
* Setting JFrame properties
* Working with Java packages
* Using `setSize()`, `setTitle()` and `setLocationRelativeTo()`
* Handling window closing with `setDefaultCloseOperation()`
* Creating and running a Java Swing application
